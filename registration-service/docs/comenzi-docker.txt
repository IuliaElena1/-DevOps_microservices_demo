# ══════════════════════════════════════════════════════════════
#  PART 1 — PORNIRE
# ══════════════════════════════════════════════════════════════
#
#  Înainte de orice, asigură-te că ești în folderul corect:
#
#    cd /Users/icordea/Documents/Projects/DevOps/registration-service
#
#  ┌─────────────────────────────────────────────────────────────┐
#  │  Pornire normală (prima dată sau după down):                │
#  │                                                             │
#  │    docker compose up -d                                     │
#  └─────────────────────────────────────────────────────────────┘
#
#  ┌─────────────────────────────────────────────────────────────┐
#  │  Pornire cu rebuild (după ce ai modificat cod):             │
#  │                                                             │
#  │    docker compose up -d --build                             │
#  └─────────────────────────────────────────────────────────────┘
#
#  ┌─────────────────────────────────────────────────────────────┐
#  │  Pornire locală fără Docker (Faza 1 - testare HTTP):        │
#  │                                                             │
#  │    uvicorn app.main:app --reload --port 8001                │
#  └─────────────────────────────────────────────────────────────┘
#
#  CE ÎNSEAMNĂ -d?
#    -d = detached = rulează în fundal
#    Fără -d, terminalul rămâne blocat cu log-urile.
#    Cu -d, terminalul e liber și containerele rulează în spate.
#
#  CE ÎNSEAMNĂ --reload?
#    Folosit doar local (fără Docker). Repornește automat serverul
#    când modifici un fișier Python. Util în development.

# ══════════════════════════════════════════════════════════════
#  PART 7 — FLUX ZILNIC RECOMANDAT
# ══════════════════════════════════════════════════════════════
#
#  La începutul zilei:
#    1. docker compose up -d          ← pornești totul
#    2. docker compose ps             ← verifici că rulează
#    3. curl localhost:8001/health    ← confirmi că API-ul răspunde
#
#  Când modifici cod:
#    1. docker compose down
#    2. docker compose up -d --build  ← rebuild cu noul cod
#
#  La sfârșitul zilei:
#    1. docker compose down           ← oprești tot
